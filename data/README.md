# Demo data

`sample_procurement_data.xlsx` is **synthetic data created for the public repository**.
It mirrors the positional column layout required by `analytics/anomaly_screen.py`, but it does not contain records copied from the original departmental reconciliation extract.

The original classroom prototype was evaluated against an official aggregate procurement extract. That source file is intentionally not redistributed in this public version because permission to use data in an academic setting does not automatically imply permission to publish the source dataset.
